# 아이핑 adapter

- 선수검색은 회원 로그인 후 `전국오픈`, `시군구`, `출전이력` 세 화면을 조회합니다.
- 검색어와 HTML은 CP949/EUC-KR로 인코딩·디코딩합니다.
- `IPING_USERNAME`, `IPING_PASSWORD`는 서버 Secret으로만 주입하며 브라우저 번들, 로그, DB에 저장하지 않습니다.
- Edge 런타임에서는 서버용 `getSetCookie()` 배열에서 `PHPSESSID`를 먼저 찾고, 헤더가 전달되지 않으면 로그인 HTML의 숨은 값을 검증해 해당 조회의 Cookie와 로그인 POST 필드에만 전달합니다. 응답 헤더와 숨은 입력값 모두에서 유효한 세션을 찾지 못하면 구조 변경 실패로 처리합니다.
- 조회마다 새 PHP 세션을 만들고 결과 처리 후 세션 식별자를 보관하지 않습니다.
- 공개 refresh 요청은 검색어별 제한과 별도로 아이핑 출처 전체에 최소 60초 간격을 적용해 서버 계정의 대리 호출을 제한합니다.
- CAPTCHA, MFA, 사람 확인 또는 기타 접근제어가 나타나면 우회하지 않고 해당 출처 갱신을 실패 처리합니다.
- 전화번호, 이메일, 주소, 생년월일, 레이팅 등 검색 목적과 무관한 개인정보는 수집하지 않습니다.
