# 아이핑 adapter

- 선수검색은 회원 로그인 후 `전국오픈`, `시군구`, `출전이력` 세 화면을 조회합니다.
- 검색어와 HTML은 CP949/EUC-KR로 인코딩·디코딩합니다.
- `IPING_USERNAME`, `IPING_PASSWORD`는 서버 Secret으로만 주입하며 브라우저 번들, 로그, DB에 저장하지 않습니다.
- 로그인 GET의 `Set-Cookie`에 담긴 `PHPSESSID`는 HTTP Cookie로, 로그인 HTML의 숨은 `PHPSESSID`는 POST 폼 토큰으로 서로 분리해 전달합니다. 숨은 폼 토큰은 필수이며, `Set-Cookie`가 전달되지 않을 때만 검증된 폼 토큰을 Cookie 값으로도 사용합니다. 로그인 POST가 새 Cookie를 발급하면 이후 확인과 검색 요청에는 회전된 값을 사용합니다.
- 조회마다 새 PHP 세션을 만들고 결과 처리 후 세션 식별자를 보관하지 않습니다.
- 로그인 POST는 비회원 문서를 먼저 돌려주고 client redirect로 회원 홈이 되므로, browser worker는 회원·사람 확인 화면이 확정될 때까지 기다린 뒤 세션을 판정합니다.
- 결과 표 끝의 빈 간격 행과 `출전이력이 없습니다`·`입상이력이 없습니다` 행은 구조 변경이 아니라 0건으로 처리합니다.
- 아이핑이 검색어 자체를 거부해 `history.back`으로 돌려보내는 화면은 출처 장애가 아닌 일시 실패로 분류합니다.
- 공개 refresh 요청은 아이핑 외부 조회를 직접 수행하지 않고 6시간 freshness·중복 작업을 확인한 private queue에 등록합니다. main 예약 worker가 10분마다 최대 한 작업을 처리하며 transient 실패만 최대 3회 재시도합니다.
- queue 등록은 선수 이름 형태만 허용하고, 원본 IP를 저장하지 않는 요청 원점 HMAC별 10분 4건과 전역 분당 신규 4건·활성 12건 제한을 함께 적용합니다.
- CAPTCHA, MFA, 사람 확인 또는 기타 접근제어가 나타나면 우회하지 않고 해당 출처 갱신을 실패 처리합니다.
- 전화번호, 이메일, 주소, 생년월일, 레이팅 등 검색 목적과 무관한 개인정보는 수집하지 않습니다.
