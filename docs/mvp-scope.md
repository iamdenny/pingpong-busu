# MVP 범위

포함: demo 검색, 동명이인 후보 분리, 상세 timeline, 출처 비교, refresh status, mock crawler, opt-in 에어핑퐁·애즈트리·대한탁구협회 디비전·오케이핑퐁·마이티티·슈퍼스타탁구·용인탁구협회 다음 카페 HTTP adapter, 로그인 필요 상태만 표시하는 아이핑 catalog, Supabase schema/RLS/seed, Edge Functions, GitHub Pages 배포.

미포함: 공식 부수 판정, BAND crawling, 전체 실사이트 backfill, 회원가입, 운영자 인증, 자동 선수 병합, 광고, 결제. 대회 부수검증 route/UI는 준비 중 설명만 제공합니다.
